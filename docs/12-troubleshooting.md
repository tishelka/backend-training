# Когда что-то не запускается

**`No module named fastapi`** — вероятно, неверное виртуальное окружение. Проверьте `python -m pip show fastapi`.

**`uvicorn: command not found`** — используйте `python -m uvicorn app.main:app --reload`.

**`Could not import module "app.main"`** — перейдите в корень репозитория, убедитесь, что есть `app/main.py`.

**`Address already in use`** — порт 8000 занят другим сервером. Остановите его или временно запустите с `--port 8001`.

**`Connection refused` на порту 5432** — PostgreSQL не запущен. Проверьте Docker Desktop и `docker compose ps`.

**`password authentication failed`** — URL, пользователь и пароль не совпадают. Изменение переменных Docker при существующем volume не меняет ранее установленный пароль.

**`relation does not exist`** — таблицы ещё нет. После настройки Alembic проверьте миграции.

**`422`** — Pydantic отклонил тело или параметры запроса. Изучите ответ в Swagger.

**`404`** — проверьте путь маршрута и идентификатор.

**`git push rejected`** — убедитесь, что отправляете ветку в **свой fork**, а не в исходный репозиторий без прав на запись.

Если просите помощи, пришлите команду, текст ошибки и что ожидали увидеть. Пароли, токены и личные данные не присылайте.
