# 03. Swagger UI и OpenAPI: тестируем API без мобильного клиента

Вот одна из самых удобных сторон FastAPI: **документация API создаётся автоматически на основе вашего кода**. Для неё не нужно вручную рисовать страницы.

После `python -m uvicorn app.main:app --reload` откройте **http://127.0.0.1:8000/docs**. Это **Swagger UI** — интерактивный интерфейс для изучения и вызова API.

## Делаем первый запрос

1. Найдите блок `GET /health`.
2. Раскройте его и нажмите **Try it out**.
3. Нажмите **Execute**.
4. Посмотрите на `Request URL`, `Response code` и `Response body`. Для старта ожидаем `200` и `{"status":"ok"}`.

Именно здесь backend-разработчик может показать мобильному разработчику, **какие маршруты есть, какие поля передавать и какие ответы получать**.

## Откуда Swagger знает параметры?

FastAPI строит спецификацию **OpenAPI** из декораторов, типов, Pydantic-моделей и описаний маршрутов. Посмотрите `/openapi.json`. Swagger UI читает эту спецификацию и показывает формы ввода.

Чтобы документация стала понятнее, добавьте `tags`, `summary`, `description` и `response_model`:

```python
@app.get("/hello", tags=["Примеры"], summary="Сказать привет")
def hello(name: str = "друг"):
    """Возвращает приветствие для имени из query-параметра."""
    return {"message": f"Привет, {name}!"}
```

## Как проверить POST с JSON

После урока Pydantic вы добавите маршрут, который принимает тело запроса. В Swagger появится блок **Request body** с примером JSON. Нажмите Try it out, измените поля, отправьте запрос — и изучите ответ.

Проверьте **два варианта**: корректное тело и некорректное (например, отрицательная цена). Статус 422 — это не «сервер сломан», а ожидаемая валидация.

## Swagger не равно автотесты

Swagger удобен для ручной проверки и общения с командой, но он **не заменяет Pytest**. Тесты позволяют проверять те же сценарии повторно при каждом изменении.

Также есть `/redoc` — другой просмотр документации. А если API опубликован вне локального компьютера, не следует считать Swagger заменой защиты доступа: это документация, а не авторизация.
