# 08. Alembic: схема БД меняется, данные остаются

Представьте, что в таблице активностей вчера были только название и цена, а сегодня понадобилась длительность. Удалять всё и создавать заново нельзя: старые данные должны сохраниться.

**Alembic** записывает последовательные версии схемы в файлы миграций.

Когда готовы SQLAlchemy-модели и подключение к PostgreSQL, один раз выполните:

```bash
alembic init migrations
```

Затем настройте `alembic.ini` и `migrations/env.py`: нужный URL БД и `target_metadata = Base.metadata` с импортом моделей. Это обязательный шаг: по умолчанию Alembic не угадает ваши модели.

```bash
alembic revision --autogenerate -m "create activities"
alembic upgrade head
alembic current
```

**Обязательно открывайте созданную ревизию**: автогенерация может ошибаться. Добавление обязательного `NOT NULL`-столбца к заполненной таблице требует продуманного значения по умолчанию или нескольких шагов миграции.
