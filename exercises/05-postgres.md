# Задание 05. Данные должны переживать перезапуск

**Теория:** [PostgreSQL](../docs/06-postgresql.md), [Docker](../docs/10-docker-and-config.md).

1. Запустите PostgreSQL через `docker compose up -d db`.
2. Откройте `psql` командой из урока.
3. В собственной учебной таблице `practice_notes` добавьте три записи.
4. Выберите записи `SELECT`, измените одну `UPDATE`.
5. Завершите сеанс `psql`, подключитесь снова и убедитесь, что данные остались.
6. Перезапустите **контейнер** `docker compose restart db` и ещё раз проверьте, что данные не исчезли.

**В PR:** приложите текст запросов (без паролей) и объясните различие между таблицей, строкой, первичным и внешним ключом. SQL можно оформить отдельным файлом `practice/yourname-notes.sql`.

**Важно:** используйте исключительно свою локальную учебную БД. Стабильность записей после перезапуска — часть задания.
