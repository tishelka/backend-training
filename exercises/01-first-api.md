# Задание 01. Мой первый FastAPI

**Перед началом:** [HTTP](../docs/01-http-and-rest.md), [FastAPI](../docs/02-fastapi.md). Стартовый `GET /health` уже работает.

**Сделайте сами:**
1. Добавьте `GET /hello`, который возвращает `{"message": "Привет, backend!"}`.
2. Добавьте `GET /activities`: пока обычный Python-список из трёх занятий (каждое — словарь с `id`, `title` и `duration_minutes`). БД пока не нужна.
3. Добавьте `GET /activities/{activity_id}`. Если запись есть, верните её; если нет — `HTTPException(404, ...)`.
4. Дайте маршрутам понятные `tags` и `summary`.

**Результат:** Uvicorn стартует, Swagger показывает все три новые операции, неизвестный ID возвращает 404.

**Не подглядывать:** не копируйте файл роутера из MVP. Попробуйте объяснить, чем query-параметр отличается от path-параметра.

**Сдать:** коммит, ссылка на PR в своём fork, примеры успешного ответа и 404.
