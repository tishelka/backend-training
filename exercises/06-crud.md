# Задание 06. CRUD + SQLAlchemy

**Теория:** [SQLAlchemy](../docs/07-sqlalchemy.md), [PostgreSQL](../docs/06-postgresql.md).

Теперь заменяем временный список Python **на настоящие записи PostgreSQL**. Создайте `app/database.py` с Engine и зависимостью, которая отдаёт Session на время запроса. Создайте `app/models.py` с таблицей `activities`.

В таблице нужны: `id` (первичный ключ), `title`, `category`, `duration_minutes`, `cost`. Типы и ограничения выберите осознанно. Пока разрешается однократно создать схему методом `Base.metadata.create_all(engine)`, **но пометьте это как временный учебный шаг**: далее будет Alembic.

Реализуйте операции:
- `POST /activities` — создать, ответ 201.
- `GET /activities` — список с ограничением количества.
- `GET /activities/{id}` — одна запись или 404.
- `PATCH /activities/{id}` — изменить название или цену, не трогая остальные поля.
- `DELETE /activities/{id}` — убрать запись, ответ 204.

**Проверка:** добавить запись, перезапустить API, получить запись по прежнему ID; изменить и прочитать снова; удалить и увидеть 404. Все действия покажите через Swagger.

**Подсказки:** разделите `ActivityCreate`, `ActivityPatch`, `ActivityOut`. Для PATCH полезен `model_dump(exclude_unset=True)`. Не отдавайте ORM-объект с непредусмотренными полями.

**Про безопасность:** это локальный учебный CRUD без пользователей, его нельзя публиковать открытым.
