# Задание 08. Тесты, которым можно доверять

**Теория:** [Pytest и HTTPX](../docs/09-testing.md).

Проверьте через `TestClient`:
- `GET /health` возвращает 200.
- `POST /activities` создаёт запись и возвращает 201.
- Пустой `title` не проходит валидацию (422).
- Неизвестный ID даёт 404.
- После изменения цена действительно обновилась.
- После удаления запись больше не находится.

**Особенно важно:** тесты, которые пишут в БД, запускайте только на **отдельной тестовой PostgreSQL-базе**. Выделите фикстуру подготовки/очистки; не направляйте её в общую БД.

Добавьте в PR вывод `python -m pytest -q` и `python -m ruff check .`. Если проверка падает, напишите почему, не скрывайте проблему.

**Дополнительный уровень:** проверьте повторный PUT на сохранение избранного так, чтобы он не создавал дубль.
