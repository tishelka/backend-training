# Задание 02. Swagger и параметры

**Теория:** [Swagger/OpenAPI](../docs/03-swagger.md).

Добавьте параметры для получения списка: `GET /activities?limit=2` и `GET /activities?category=walks`.

**Требования:**
- `limit` необязательный, по умолчанию 10, допустимо от 1 до 100 (подсказка: `Query`).
- `category` необязательный; если указан, отдавайте только совпадающие категории.
- В Swagger у каждого параметра должно быть описание.
- Проверьте в `/docs` значения `limit=2`, `limit=0` и неизвестную категорию.
- Добавьте в описание PR **коды ответов и примеры**, которые реально увидели.

**Что понять:** Swagger берёт форму для ввода параметров из сигнатуры функции и её аннотаций. Для проверки запроса мобильный клиент не нужен.

**Готово, если:** корректный limit сокращает список, нулевой приводит к 422, а OpenAPI содержит эти параметры.
