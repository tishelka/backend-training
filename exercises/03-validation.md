# Задание 03. Pydantic: валидируем запросы

**Теория:** [Pydantic](../docs/04-pydantic.md).

Создайте `app/schemas.py` и модель `ActivityCreate`: `title` — непустая строка до 100 символов, `category` — одна из `walks`, `games`, `sport`, `duration_minutes` — положительное число, `cost` — число от нуля. Подумайте, где уместнее `int`, а где `float`.

Добавьте `POST /activities`. Пока хранение в памяти допустимо. ID должен задавать сервер, а не клиент.

**Проверьте в Swagger:**
1. Корректный JSON добавляет запись.
2. Отрицательная цена → 422.
3. Пустой заголовок → 422.
4. Неизвестная категория → 422.
5. Лишнее поле: выберите и реализуйте строгую политику `extra="forbid"`.

**Что написать в PR:** чем Pydantic-схема запроса отличается от SQLAlchemy-модели таблицы? Пока второй ещё нет, ответьте своими словами.

**Не делайте задание за FastAPI:** не пишите вручную десять `if` для проверки тела запроса — изучите `Field` и `Enum`/`Literal`.
